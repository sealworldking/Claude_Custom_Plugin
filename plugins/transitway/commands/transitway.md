description: 등록한 경로(way)별 대중교통 소요시간을 계산해 추천 경로와 함께 카카오톡으로 보낸다
---

transit MCP로 오늘의 경로 브리핑을 만들어 카카오톡으로 전송하라.

1. `get_ways`로 등록된 경로(way)를 확인한다. 없으면 사용자에게 경로를 물어
   `set_way`로 저장한다. (예: set_way id="way1" path="출발지 -> 환승역 -> 도착지")
2. `brief_ways`를 호출해 경로별 소요시간 + 추천(최단) 경로 브리핑 텍스트를 받는다.
3. 그 텍스트를 그대로 `KakaotalkChat-MemoChat` 도구로 나에게 전송한다. 200자 이내, 하나의 메시지.

출력 형식:
```
[오늘의 경로 추천]

추천: way2 / 39분

경로 상세: [출발지]→[환승역]→[도착지]

다른 경로:
way1 52분 / way2 39분 / way3 47분
```
